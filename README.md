# Machupicchu Beyond

Sitio de presentación creado con Astro y generación estática.

## Desarrollo

```sh
npm install
npm run dev
```

## Compilación y vista previa

```sh
npm run build
npm run preview
```

La página principal reúne la esencia y los valores definidos en el manual de marca, junto con los datos de contacto que aparecen en el material del cliente. El dominio final todavía no está configurado; por eso el proyecto no fija canonical ni genera sitemap.
